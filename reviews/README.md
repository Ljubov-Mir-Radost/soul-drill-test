# Public publication reports

Only `task-ID.publication.json` belongs here. Never upload editor drafts, full English/BHS originals or personal Soul Drill backups.

A publication contains the public practice, two human review declarations, exact content/rules/material hashes and the base-catalog hash. A hash is not a signature. The owner must verify the reviewers through a known channel before merging. No substitute publisher is appointed or required.

The editor prepares `data/content.v2.json` and this publication file together. Upload both in a new branch, open a PR, wait for **Content validation**, inspect the diff, then merge. If the base catalog changed, prepare both files again against the latest catalog.
