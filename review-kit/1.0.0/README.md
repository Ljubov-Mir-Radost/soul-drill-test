# Soul Drill — правила за проверувачи / pravila za provjeravatelje, 1.0.0

Без најава можеш да подготвиш нацрт или проверка во /editor/. Не се објавува автоматски. Сопственикот ги прима датотеките и објавува преку GitHub. Заменски објавувач е само идна можност.

1. Преземи го пакетот преку уредникот. SHA-256 идентификува точни правила, не личност.
2. Во нов ChatGPT/Work разговор приложи ја ready.json практиката, соодветниот извор и овој пакет. Користи MK-PROMPT или BHS-PROMPT. Не е потребна историјата на сопственикот.
3. Прочитај го AI извештајот и сам спореди со изворот. Не потврдувај јазик што не го владееш.
4. Во „Провери практика“ избери само свој јазик, внеси ознака, резултат и забелешка. Потврди ја сопствената проверка и преземи review.json.
5. Достави ја практиката и одделните MK/BHS review.json датотеки на сопственикот. Изворните оригинали достави ги преку договорен приватен канал.

BHS: Uvezi praksu, odaberi samo jezik koji provjeravaš, usporedi s izvorom i izvezi zaseban izvještaj. AI nije ljudsko odobrenje. Izvornike ne stavljaj u javni GitHub. Obrazac nikada ne traži GitHub lozinku ili token.

Точна верзија: README и датотеките во оваа папка не се препишуваат по објавување. Следна промена добива нова верзија. Во GitHub притисни `y` на страницата со фајлот за permalink со точен commit. Во уредникот е достапен еден Markdown пакет проверен според manifest.json. Во секој извештај се запишува rulesDigest. Стар пакет не се заменува тивко.

EXAMPLE.json е целосен синтетички пример за вежба, НЕ вистинско Мурли и НЕ одобрена практика. Не го објавувај како автентичен извор.

При увоз на EXAMPLE.json избери „Примени тековни правила“. Примерот има нулта rulesDigest ознака за да не создава кружен отпечаток на пакетот.
